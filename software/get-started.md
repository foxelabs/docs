# Get Started

Welcome to the **Foxe Labs** software documentation.

## What is Foxe Labs?

Foxe Labs builds **open-source WordPress plugins and PHP libraries**. Our focus is on small, focused tools that do one thing well — lean by default, with the heavier features kept in optional add-ons rather than bundled into everything.

This site is the official home for our product documentation: installation guides, what each setting does, WP-CLI commands, developer reference, and version history.

## Our Products

### Loggedin

Limit the number of **concurrent sessions** a WordPress user can have, and force logouts when they exceed it. The core plugin stays lean; add-ons cover live session management, per-user and per-role limits, and real-time logout.

- ⚙️ **[General Settings](./loggedin/general-settings)** — Every available setting explained
- 🧩 **[Add-ons](./loggedin/addons/)** — Extend it when you need more
- 🖥️ **[WP-CLI](./loggedin/wp-cli)** — Manage sessions from the command line
- 🧑‍💻 **[Developer Docs](./loggedin/developer-docs)** — Hooks, filters and internals
- 🗒️ **[Changelog](./loggedin/changelog)** — Version history

### Lazy Load for Comments

Stop comments from loading on every page view. They load **on scroll or on click** instead, which keeps comment-heavy pages fast.

- 🚀 **[Getting Started](./lazy-load-for-comments/getting-started)** — Install and pick a loading mode
- ⚙️ **[Loading Behaviour](./lazy-load-for-comments/loading-behaviour)** — On scroll, on click, or both

## Installing and Updating

Our free plugins install like any other WordPress plugin — search for them under **Plugins → Add New** in your admin, or upload the ZIP. Premium add-ons are downloaded from your account after purchase and installed the same way; see the [Loggedin add-ons guide](./loggedin/addons/) for the full walkthrough.

Keep plugins updated from **Dashboard → Updates**. Updates usually contain fixes for problems we have already found, so it is worth staying current before reporting an issue.

## Need Help?

If you need help with one of our **free** WordPress plugins, please open a support request on the plugin's WordPress.org support forum. For premium add-ons, email **[support@foxelabs.com](mailto:support@foxelabs.com)**.

Whichever route you take, these details help us help you faster:

- **A link to your site**, ideally the specific page where the problem shows up.
- **What you are seeing** — the exact error text, or a screenshot.
- **Your WordPress version**, from the *At a glance* panel on your Dashboard.
- **Your plugin version**, and whether the problem persists on the latest release.

We answer everyone as quickly as we can. Paid users get priority, so if you need immediate assistance, consider a paid version of the product.
